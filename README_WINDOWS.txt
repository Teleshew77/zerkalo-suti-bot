TELEGRAM BOT «ЗЕРКАЛО СУТИ» — WINDOWS

1. Распакуйте папку zerkalo_bot_windows в удобное место, например на Рабочий стол.
2. Откройте файл .env.example через Блокнот, заполните настройки и сохраните копию под именем .env (именно .env, без .txt).
   BOT_TOKEN — токен BotFather (никому не отправляйте).
   STARS_PRICE — цена в Telegram Stars, например 250 (не эквивалент 430 ₽).
   CHANNEL_URL — ссылка на канал; её можно будет поменять позже в .env.
   SUPPORT_CONTACT — контакт поддержки.
   FOLLOWUP_SECONDS=7200 — задержка 2 часа.
   ADMIN_IDS — числовой Telegram user ID администратора.
3. Дважды щёлкните start_windows.bat. Скрипт создаст виртуальное окружение и установит зависимости.
4. Бот запустится в окне командной строки. Не закрывайте его, пока тестируете бота.
5. Остановить: Ctrl+C в этом окне.

Если файл .env ещё не создан, start_windows.bat сам скопирует .env.example в .env и откроет Блокнот. Заполните файл, сохраните его и запустите start_windows.bat повторно.

База bot.sqlite3 создаётся рядом с bot.py. Не удаляйте её — там хранятся покупки и запланированные сообщения.
Для изменения ссылки на канал замените CHANNEL_URL в .env и перезапустите бота.
